# Учебное задание

### Задание:
Разработать консольную программу, позволяющую анализировать успеваемость группы студентов.
### Требования: 
Использовать массивы, циклы, операторы ветвления, реализовать хотя-бы один собственный метод. Обеспечить проверку корректности вводимых данных.

Запросить у пользователя количество студентов в группе.

Для каждого студента ввести имя и три оценки (от 2 до 5).

Рассчитать средний балл каждого студента.

Определить успеваемость студента: (4,5–5,0 — отлично; 3,5–4,49 — хорошо; 2,5–3,49 — удовлетворительно; ниже 2,5 — неудовлетворительно.)

Рассчитать средний балл всей группы.

Найти студента с самым высоким средним баллом.

Реализовать меню для повторного выполнения операций без перезапуска программы.
